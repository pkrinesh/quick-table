# quick-table

A TanStack Table wrapper that makes tables easy to build.

## Packages

- `@quick-table/react` - React bindings
- `@quick-table/core` - Core logic

## Development

```bash
# Install dependencies
bun install

# Start playground
bun run dev

# Build packages
bun run build

# Lint
bun run lint

# Type check
bun run typecheck
```
